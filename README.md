# DPanel 应用商店

面向 [DPanel](https://dpanel.cc/) 的 Docker 应用商店数据仓库，由 [`新疆萌森软件开发工作室`](https://blog.lifebus.top/) 提供技术支持。

- 新仓库地址：<https://github.com/MengSenStudio/AppStore-DPanel>
- 应用源仓库：[MengSenStudio/AppStore-1panel](https://github.com/MengSenStudio/AppStore-1panel)

`apps/` 目录由 `AppStore-1panel` 的 `Process Apps and Commit Changes` 工作流自动生成并推送，请勿手动修改。

## 目录结构

```
apps/        应用源文件（应用名/版本/docker-compose.yml）
LICENSE      开源协议
```
